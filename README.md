**krab** — это безопасное, легковесное локальное хранилище секретов (паролей, заметок, ключей, TOTP-токенов) на Rust. 

Все данные хранятся в **одном зашифрованном файле** (по умолчанию `vault.krabic`). Без знания мастер-пароля файл неотличим от псевдослучайного шума. Проект построен по принципу разделения ответственности: *«ядро хранит и считает, интерфейс показывает»*.

---

## ⚡ Особенности

- **Криптография нового поколения**: AEAD-шифрование `XChaCha20-Poly1305` с 24-байтовым nonce (новый nonce генерируется при каждом сохранении).
- **Защита мастер-пароля (KDF)**: `Argon2id` с динамической калибровкой параметров под производительность процессора (~0.5–1.0 с на вычисление).
- **Целостность и AAD**: Фиксированный 54-байтовый заголовок полностью входит в расчёт аутентификационной пломбы Poly1305. Любая попытка подменить заголовок или ослабить параметры KDF делает файл нечитаемым.
- **Атомарное сохранение**: Запись во временный файл с последующим `fsync` и атомарной заменой (в любой момент на диске существует либо старое, либо новое валидное состояние).
- **Гигиена памяти**: Зануление секретов в ОЗУ (`zeroize` / `ZeroizeOnDrop`), отсутствие секретов в выводах `Debug`.
- **Интерактивный CLI**: Красивый терминальный интерфейс с поддержкой `NO_COLOR`, анимированными спиннерами на время вычислений KDF, табличным выводом `comfy-table` и чистым выходом по `Ctrl+C`.

## 🔒 Криптографический стек и формат файла

| Задача | Решение | Крейт |
|---|---|---|
| **Шифрование + Пломба** | `XChaCha20-Poly1305` (AEAD, 24-byte nonce, 16-byte auth tag) | `chacha20poly1305` |
| **Пароль → Ключ** | `Argon2id` с автокалибровкой памяти и проходов | `argon2` |
| **Сериализация тела** | `CBOR` (структурированный бинарный формат) | `ciborium` |
| **Очистка памяти** | Безопасное затирание нулями при Drop | `zeroize` |
| **Генератор случайности** | Криптостойкий ГСЧ операционной системы | `getrandom` |

### Структура файла `.krabic` (открытый заголовок 54 байта + тело + пломба)

```text
[ Заголовок 54 байта, AAD ] [ Зашифрованное тело CBOR ] [ Пломба Poly1305 (16 байт) ]
```

1. **Magic** (`KRAB`, 4 байта)
2. **Версия** (`1`, 1 байт)
3. **Параметры Argon2id**: память в KiB (4 байта), проходы (4 байта), параллелизм (1 байт)
4. **Соль KDF** (16 случайных байт)
5. **Nonce шифра** (24 случайных байта, меняется при каждой перезаписи)

## 🛡️ Модель угроз

### Защищаем от:
- Потери или кражи физического устройства;
- «Холодного» копирования файла хранилища и офлайн-перебора паролей по словарю (благодаря затратному Argon2id);
- Модификации и повреждения заголовка файла (благодаря Poly1305 AAD).

### НЕ защищаем от:
- Вредоносного ПО (кейлоггеров) на работающей скомпрометированной ОС;
- Дампов физической памяти в момент работы программы.

## 🚀 Быстрый старт (CLI)

### Установка и сборка

Требуется **Rust** (версия 1.85+):

```bash
git clone https://github.com/ascezis/krab.git
cd krab
cargo build --release
```

### 1. Создание нового хранилища (`init`)
```bash
cargo run -p krab-cli -- init
# или указав конкретный путь:
cargo run -p krab-cli -- -v my_vault.krabic init
```
Команда запросит мастер-пароль, проверит сложность, выполнит калибровку параметров Argon2id и создаст файл.

### 2. Добавление записи (`add`)
```bash
cargo run -p krab-cli -- add
```
Интерактивный визард позволит выбрать тип записи (`Login`, `SecureNote`, `Key`, `Totp`, `Other`), ввести логин, пароль, URL, заметку и теги.

### 3. Просмотр списка записей (`list`)
```bash
cargo run -p krab-cli -- list
```
Отображает форматированную таблицу записей с их типами, тегами и краткими идентификаторами.

## 📂 Структура репозитория

```text
krab/
├── Cargo.toml         # Манифест Cargo Workspace
├── README.md          # Этот файл
├── krab-core/         # Библиотека ядра (криптография, хранилище, модель данных)
│   ├── src/
│   │   ├── header.rs  # Парсинг и сборка 54-байтного бинарного заголовка
│   │   ├── kdf.rs     # Вывод ключа через Argon2id и автокалибровка
│   │   ├── storage.rs # Атомарная запись на диск (tempfile + fsync)
│   │   ├── model.rs   # Записи (Entry), поля (Field) и типы
│   │   └── vault.rs   # Главный фасад хранилища (open, create, save, rekey)
│   └── tests/         # Интеграционные тесты ядра (47 тестов)
├── krab-cli/          # Консольный клиент
│   └── src/
│       ├── main.rs    # Диспетчер команд CLI и обработчики
│       └── ui.rs      # UI модуль: цвета, баннер, таблицы, спиннеры
└── design/            # Наработки по дизайну и скрипт генерации баннера
```
